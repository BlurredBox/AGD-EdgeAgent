# Security policy

## Reporting a vulnerability

Email **harutyun@blurredbox-agd.com** (the founders' address on blurredbox-agd.com) with the subject "Edge agent security". Please include the version (`edge_agent` package version or release tag), what you observed, and steps to reproduce. Do not post details in a public issue before we have answered.

We aim to acknowledge a report within 3 working days and to tell you what we will do about it within 14 days. We are a small team and do not run a bug bounty.

## Scope

This repository mirrors the edge agent from BlurredBox release tags. In scope: the code in `edge_agent/`, `corpus/`, `packaging/edge_agent/` and its documented behaviour (what leaves the network, local file permissions, signing, installers). The BlurredBox service itself is not in this repository; report problems with it to the same address.

## Supported versions

Only the most recent release tag mirrored here receives fixes.
